SQL → Mapping Document

วางสคริปต์ .sql แล้วได้ไฟล์ .xlsx ที่จัดหน้าตามฟอร์แมตเอกสาร mapping เดิม — อ่าน subquery, join, where และไล่สาย lineage ของทุกคอลัมน์ให้อัตโนมัติ

1 สคริปต์ต้นทาง

ลากไฟล์ .sql มาวาง — ทีละหลายไฟล์ได้ สคริปต์ที่ต่อกันเป็นทอด ๆ ให้ใส่มาพร้อมกัน ระบบจะไล่ lineage ข้ามไฟล์ให้

2 ข้อมูลหัวเอกสาร

3 Column mapping — แก้ไขได้ก่อนสร้างไฟล์

ช่องที่มีแถบสีเหลืองคือช่องที่พิมพ์แก้เอง — วิเคราะห์สคริปต์ใหม่จะไม่ทับค่านี้ กด ↻ ที่หัวคอลัมน์ของ source ไหน เพื่อดึงค่าของ source นั้นกลับมาจากสคริปต์

เทียบกับ DDL ของตารางปลายทาง

เรียงข้อมูลเป็น Column name → # → Datatype วางติดกันบรรทัดเดียวหรือแยกบรรทัดก็ได้ รองรับไฟล์ CREATE TABLE ด้วย

◇ ER diagram — Mermaid สำหรับ draw.io

แยกโค้ดตามสคริปต์ 1 สคริปต์ = 1 หน้า (page) ใน draw.io — เส้นเชื่อมลากจากคอลัมน์ PK ไปยังคอลัมน์ FK ตาม ON condition จริงในสคริปต์

draw.io editor — ER diagram

แก้ไขได้เลยในกรอบนี้ กด Save ในเมนู draw.io เพื่อดึง XML ที่แก้แล้วกลับมา — ต้องต่ออินเทอร์เน็ตถึงจะโหลดได้ ถ้าเปิดไม่ขึ้นให้ใช้ปุ่มดาวน์โหลด .drawio แทน

  1. เปิด draw.io แล้วสร้าง หน้าใหม่ (+ Add page) แยกจากหน้า Data Flow Diagram
  2. เมนู + (Insert) → Advanced → Mermaid
  3. วางโค้ดข้างบนทั้งบล็อก แล้วกด Insert
  4. ถ้ามีหลายสคริปต์ ให้สลับแท็บด้านบนแล้วทำซ้ำในหน้าใหม่ของแต่ละสคริปต์
